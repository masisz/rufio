## 画面とモード

Files モードでは、最上段に現在のパス、その下にブックマーク一覧、左にファイル一覧、右にプレビューを表示します。最下段はモードのタブです。

| キー | モード |
|------|--------|
| （起動時） | **Files** – ファイルの閲覧と操作 |
| `C` | **Config** – `~/.config/rufio/` を Files と同じ操作で閲覧 |
| `G` | **Search** – 全ブックマーク配下のファイル名・内容を横断検索 |
| `L` | **Logs** – コマンド実行ログの閲覧 |
| `J` | **Jobs** – バックグラウンドのコマンド・スクリプト・ZIP 処理 |
| `?` | **Help** – 現在の画面の上に開くヘルプメニュー |

`ESC` で現在のモードを抜けます。Files・Config 以外のモードでは、`Shift+Tab` で前のモードに切り替わります。

## 移動

| キー | 操作 |
|------|------|
| `j` / `↓` | 下へ |
| `k` / `↑` | 上へ |
| `h` / `←` | 親ディレクトリへ |
| `l` / `→` / `Enter` | ディレクトリに入る |
| `g` | 先頭へ |
| `}` | 末尾へ |
| `R` | 再読み込み |
| `0` | 起動したディレクトリへ戻る |
| `q` | 終了（確認あり） |
| `T` | 終了して、シェルを現在のディレクトリへ移動（[シェル連携](#シェル連携)） |

マウスでも、クリックで選択、ホイールで一覧やプレビューをスクロールできます。

## プレビュー

テキストのプレビューは先頭64 KiBまで読み込みます。PDFの本文はプレビューせず、ファイル移動時の読み込みを省きます。

右側のペインに選択中のファイルを表示します。`bat` があればコードをハイライトします。`.zip` は展開せずにエントリ一覧（サイズ・圧縮方式・更新日時・名前）を表示します。

| キー | 操作 |
|------|------|
| `P` | 全画面プレビュー（ファイル一覧を隠す） |
| `j` / `k` | スクロール |
| `Ctrl+D` / `Ctrl+U` | 1 ページ下 / 上 |
| `y` | ファイルパスをクリップボードへコピー |
| `ESC` | ファイル一覧に戻る |

### 画像

画像（`.png` / `.jpg` / `.gif` / `.bmp`）は、Kitty グラフィックスプロトコルで端末に描かせます。kitty・Ghostty・WezTerm・Konsole が対応しており、起動時に 1 回だけ端末へ問い合わせて、対応していなければ黙ってテキスト表示に戻します。

| 状況 | 表示 |
|------|------|
| 対応端末・8 MiB までの PNG | ペインに収めた画像（分割表示と `P` のどちらでも） |
| それ以外の形式（JPEG・GIF・BMP） | 形式・寸法・ファイルサイズをテキストで表示（デコードはネイティブ実装の段で対応） |
| 非対応端末・tmux の中 | 同じテキスト表示 |

プレビューモード（`P`）では画像を拡大できます。

| キー | 操作 |
|------|------|
| `+` / `-` | 25% 刻みで拡大・縮小（最大 4 倍）。元画像の一部を端末に出してもらう方式なので、デコードは要りません |
| `0` | ペインに収める |
| `h` / `j` / `k` / `l` または矢印 | 拡大中の表示位置を動かす |

画像の下のセルは空白のまま確保するので、ファイル一覧やステータス行が読めなくなりません。別のファイルを選んだとき、ヘルプ・検索画面・コマンドモードを開いたとき、rufio を終了したときには画像を消します。別のファイルへ移るときは先に画像を消し、約 80ms 後に次を送るので、`j` を押し続けて画像のフォルダを辿っても転送が溢れません。通知などでセルが上書きされた画像は置き直し、一度見た画像に戻ったときは読み直しも符号化もしません。`RUFIO_IMAGE_PREVIEW=0` で画像表示を完全に無効化できます。設計と残りのフェーズは [image_preview_design_ja.md](./image_preview_design_ja.md) にあります。

### プレビュー内の検索（`/`）

プレビュー中の `/` は、そのファイルの中を検索します。入力すると現在位置以降の最初の一致へ飛び、`Enter` で確定、`n` / `N` で次 / 前の一致へ（端では反対側へ回ります）、`ESC` で解除します（もう一度押すとプレビューを抜けます）。一致箇所はハイライトされ、現在の一致だけ別の色で表示します。プレビューモードではファイルの先頭 64 KiB・最大 20,000 行を読み込むため、検索はその範囲が対象です。

### 表を行列で表示

`.csv` / `.tsv` / `.tab` / `.xlsx` / `.xlsm` / `.ods`、および `sqlite3` コマンドがある場合は SQLite のデータベースを、行と列で表示します。

```
 sales.csv [PREVIEW MODE]
 R3C2 price  |  hjkl: move  y: copy  ESC: back
   | A name | B price | C stock |
 1 | apple  | 120     | 30      |
 2 | みかん | 150     | 8       |
 3 | banana | 80      | 12      |
3 rows  3 cols
```

見出しには列ラベル（A・B・C…）が付き、スクロール中もヘッダ行は固定されます。最下行には行数・列数・判定した文字コード・読み込み上限に達したか・ペインに収まらない列数が出ます。

プレビューモードではセルカーソルを動かせます。

| キー | 操作 |
|------|------|
| `h` / `j` / `k` / `l` または矢印 | セルを移動（カーソルに合わせて縦横にスクロール） |
| `Ctrl+D` / `Ctrl+U` | 1 画面分の行移動 |
| `g` / `}` | 先頭行 / 最終行 |
| `0` / `$` | 先頭列 / 最終列 |
| `Space` | カーソル位置のカラムを選択 / 解除 |
| `/` | 行を絞り込む（下記） |
| `y` | カーソル位置のセル、またはカーソル行の選択カラムをカンマ区切りでコピー |
| `Y` | 行全体を CSV の 1 行としてコピー |
| `[` / `]` | 前 / 次のシート（Excel のシート、SQLite のテーブル） |
| `t` | シート／テーブル一覧を開く（`j`/`k` で移動、`Enter` で開く、`ESC` で閉じる） |
| `ESC` | ファイル一覧に戻る |

`Space` でカーソル位置のカラムを選択すると、ファイル一覧の選択済みアイテムと同じ印が付き、ファイル名の下の行に選択中のカラム（`cols A,C`）が出ます。カラムを選んでいる状態で `y` を押すと、カーソル行のそのカラムのセルを列の順にカンマ区切りで連結して（`apple,30`）コピーします。カンマや改行を含むセルは CSV として読み戻せるようクォートします。`Y` は選択に関係なく行全体をコピーし、シートを切り替えると選択は解除されます。

### 行の絞り込み（`/`）

表プレビューの `/` は行を絞り込みます。条件はカンマ区切りで並べます。

| 入力 | 意味 |
|------|------|
| `price > 100` | 比較（`=`、`!=`、`<>`、`>`、`>=`、`<`、`<=`）。両辺が数値なら数値として比較 |
| `name a%` | `LIKE 'a%'`。`%` は任意の文字列、`_` は 1 文字 |
| `name apple` | `LIKE '%apple%'`。列のどこかに含まれれば一致 |
| `note "red, sweet"` | 引用符で囲むと、カンマや空白を含む値をそのまま渡せる |
| `apple` | 列を書かなければ全列が対象 |
| `price > 100, name a%` | 複数条件（すべて満たす行だけ残る） |

列名は大文字小文字を区別せず、列ラベル（`A`、`B`…）でも指定できます。`Enter` で適用すると、ファイル名の下の行に `filter: price > 100 (2 rows)` のように出ます。`ESC` で絞り込みを解除し、もう一度押すとプレビューを抜けます。シートを切り替えても解除されます。

SQLite のテーブルでは、条件を読み取り専用の `SELECT ... WHERE` に組み立ててデータベース側で実行するため、プレビューの読み込み上限より後ろの行も見つかります。値は必ず引用符付きのリテラルとして渡し、列名は実在する列に解決してから使うので、入力がそのまま SQL になることはありません。Excel や CSV は読み込み済みの行を Ruby 側で判定します。

`t` で Excel のシートや SQLite のテーブルの一覧を開けます。表示中のシートには `>` が付き、長い一覧は `Ctrl+D` / `Ctrl+U` でページ送り、`g` / `}` で先頭・末尾へ移動できます。シートが 1 枚だけのファイルには一覧がありません。

セル移動は `move_up` / `move_down` / `navigate_parent` / `navigate_enter` のキーバインド設定に従うため、`hjkl` を変更していればそれが反映されます。

UTF-8・UTF-16（BOM つき）・CP932・EUC-JP を自動判定するので、Shift_JIS の CSV も文字化けしません。`.csv` / `.tsv` は先頭 512 KiB・1000 行まで読み込みます。表示しているシートだけを読み込むため、Excel の他のシートや SQLite の他のテーブルは切り替えるまで読み込みません。10 MiB を超える表計算ファイルや、解析できないファイルは ZIP のエントリ一覧表示に戻ります。

コピーは `pbcopy` / `clip` / `wl-copy` / `xclip` / `xsel` があればそれを使い、無ければ OSC 52 を使います（SSH 越しでも端末が対応していれば動作。tmux では `set -g set-clipboard on` も必要）。`config.rb` の `CLIPBOARD_COMMAND` で任意のコマンドを指定でき、`rufio -c` でどれが使われるか確認できます。読み込み上限や区切り文字、ヘッダ行の扱い、文字コードは `TABLE_PREVIEW` で変更できます。

## ファイル操作

| キー | 操作 |
|------|------|
| `o` | ファイルを対応するアプリで開く（[設定](#設定) の `APPLICATIONS`） |
| `e` | 現在のディレクトリを OS のファイルエクスプローラーで開く |
| `a` | ファイル作成 |
| `A` | ディレクトリ作成 |
| `r` | リネーム |
| `d` | 削除（確認あり） |
| `Space` | 選択 / 選択解除 |
| `m` | 選択したアイテムを現在のディレクトリへ移動 |
| `c` | 選択したアイテムを現在のディレクトリへコピー |
| `x` | 選択したアイテムを削除（確認あり） |

移動・コピーは、`Space` で選択してから移動先のディレクトリへ行き、`m` または `c` を押します。
コピー先に同じ名前がある場合は連番を付けてコピーします（`name_1.txt`、`dir_1`）。移動先に同じ名前がある場合はエラーになります。

## ZIP の展開・圧縮

`Space` でアイテムを選択して `z` を押します。

- **選択がすべて `.zip` の場合**: それぞれを現在のディレクトリの `<名前>/` に展開します（同名があれば `<名前> 2/`、`<名前> 3/` …）
- **それ以外の場合**: アーカイブ名を尋ねたうえで、選択したアイテムを現在のディレクトリに 1 つの `.zip` として圧縮します。`Enter` で提案された名前（1 件なら `<アイテム名>.zip`、複数なら `Archive.zip`）を使います

処理はジョブとして実行されます。進捗の確認とキャンセルは Jobs モードで行います（`J` → `x`）。展開に失敗・キャンセルした場合は途中まで展開したフォルダを削除し、完了するとファイル一覧を更新します。

展開時は書き込み前にアーカイブ全体を検証します。パストラバーサル・絶対パス・データ範囲が重なるエントリ、合計 16 GiB・10 万エントリ・圧縮率 1000:1（1 MiB 超のエントリ）を超えるアーカイブを拒否します。シンボリックリンクと暗号化エントリはスキップし、CRC-32 を検証し、既存ファイルは上書きしません。対応する圧縮方式は Stored と Deflate です。

何も選択していないときの `z` は zoxide 履歴を開きます。

## フィルターと検索

| キー | 操作 |
|------|------|
| `f` | 入力に合わせて一覧を絞り込む（`Enter` で確定、`ESC` で解除） |
| `/` | 検索（いる場所によって対象が変わる） |

検索キーは `/` だけで、対象はモードによって変わります。

| `/` を押す場所 | 検索する対象 |
|----------------|--------------|

| 表プレビュー | 表示中のシート／テーブルの行を絞り込む |

## 検索画面（ファイル一覧の `/`）

`/` は現在のディレクトリ配下を再帰的に検索します（ブックマークは検索しません）。ファイル名はあいまい検索（よく一致したものから並び、一致文字をハイライト、絞り込みはバックグラウンド）で、内容検索は大文字小文字を区別しないリテラル検索です。隠しファイルと通常ファイルへのリンクも含め、走査しながら結果を表示します。

| キー | 操作 |
|------|------|
| 文字入力 | ファイル名: あいまい検索。内容: 大文字・小文字を区別しないリテラル（部分一致）検索 |
| `Tab` | **File names（ファイル名）** と **Content（内容）** を切り替え |
| `↑` / `↓`、`Ctrl+J` / `Ctrl+K`、`Ctrl+N` / `Ctrl+P` | 結果を選択 |
| `Enter` | Files モードでそのファイルの場所へ移動 |
| `Ctrl+U` | 検索語をクリア |
| `ESC` | Files モードに戻る |

- あいまい検索は、文字が順番どおりに現れれば離れていても一致します（`sctrl` で `search_controller.rb` が見つかります）。ASCII の英字は大文字小文字を区別せず、日本語はそのまま照合します。
- 一致箇所はハイライトされます。内容検索ではファイル・行番号・一致した行を表示します。
- 検索中は黄色の `Searching...` が動き、完了すると緑の `Search complete` に変わります。
- アクセスできないディレクトリとディレクトリのシンボリックリンクはスキップします。通常のテキストは UTF-8 として読み、先頭 8 KB に NUL バイトがあるファイルはバイナリとして扱います。
- 照合には同梱の Zig ライブラリを使い、利用できない場合は Ruby 実装に切り替えます（`RUFIO_NATIVE_FUZZY=0` で Ruby を強制）。

### 文書の内容検索

Python・Microsoft Office・変換ツールなしで文書の中も検索できます。

| ファイル | 検索する内容 | 結果の位置 |
|----------|--------------|------------|
| `.pdf` | 抽出できる文字列 | ページ |
| `.xlsx` | セルの文字列と保存済みの値 | シートとセル |
| `.pptx` | スライドの図形・表内の文字列 | スライド |

抽出した文字列はメモリにキャッシュし（最大 64 文書・約 16 MiB）、ファイルが変わると再抽出します。画像だけの PDF には OCR が必要で、これは含みません。旧形式の `.xls` / `.ppt` とスライドノートは対象外です。

### 拡張子・ディレクトリの除外

`~/.config/rufio/config.rb` に次を追加して rufio を再起動します。ファイル名・内容の両方に適用されます。

```ruby
SEARCH_EXCLUDED_EXTENSIONS = %w[.png .jpg .zip .tar.gz .log /.git /node_modules /.DS_Store].freeze
```

大文字・小文字は区別せず、先頭のドットは省略できます。デフォルトの `[]` は何も除外しません。`/` で始まる要素は名前の指定になり、その名前のディレクトリは配下ごと、名前が完全に一致するファイルは単体で除外します。

## ブックマークと履歴

| キー | 操作 |
|------|------|
| `b` | 現在のディレクトリをブックマーク |
| `B` | ブックマークメニュー |
| `1`〜`9` | ブックマーク 1〜9 へ移動 |
| `z` | zoxide 履歴（何も選択していないとき） |

`B` のメニュー:

1. 現在のディレクトリをブックマークに追加
2. 現在のディレクトリをスクリプトパスに追加
3. スクリプトパスの管理（`d` で削除、`Enter` で移動、`ESC` で閉じる）
4. ブックマーク一覧

## コマンドモード

`:` でコマンドモードを開きます。`Tab` で補完、`↑` / `↓` で履歴、`Enter` で実行、`ESC` でキャンセルです。

| 入力 | 動作 |
|------|------|
| `@名前` | スクリプトパスまたは現在のディレクトリのスクリプトを実行 |
| `rake:タスク` | 現在のディレクトリの `Rakefile` のタスクを実行 |
| `!コマンド` | シェルコマンドをバックグラウンドで実行 |
| `cd <パス>` | ディレクトリへ移動 |
| `名前` | 組み込みコマンド・DSL コマンドを実行 |

```
:@build              # スクリプト（Tab で名前を補完）
:rake:test           # Rake タスク（Rakefile・rakefile・Rakefile.rb に対応）
:!git status         # シェルコマンド
:hello               # 組み込みのサンプルコマンド
```

### パスへ移動

`:cd` の後ろにパスを貼り付けると、その場所へ移動します。

```
:cd ~/projects/app             # ディレクトリ
:cd '/path/with space/a.txt'   # ファイル: フォルダへ移動してそのファイルを選択
:cd sub                        # 現在のディレクトリからの相対パス
:cd -                          # 直前のディレクトリへ戻る
:cd                            # ホームディレクトリ
```

コピー時に付く両端の引用符・末尾の改行・`\ ` エスケープ・`file://` URL はそのまま受け付けます。`Tab` でディレクトリ名を補完できます。パスが存在しない場合は移動せずにエラーを表示します。

## スクリプト

登録したスクリプトパスと、いま開いているディレクトリにあるスクリプトを `:@名前` で実行できます。実行時の作業ディレクトリは、いま開いているディレクトリです。

| 拡張子 | 実行に使うもの |
|--------|----------------|
| `.rb` | Ruby |
| `.py` | Python 3 |
| `.sh` | シェル |
| `.js` | Node.js |
| `.ts` | ts-node |
| `.pl` | Perl |
| `.ps1` | PowerShell |

スクリプトパスは次の順に探し、最初に名前が一致したものを使います。

1. プロジェクトの `./rufio.yml`
2. `~/.config/rufio/script_paths.yml`
3. `/etc/rufio/script_paths.yml`

ディレクトリを登録するには、rufio でそのディレクトリを開いて `B` → `2` を押します。

## DSL コマンド

`~/.config/rufio/commands.rb`（`~/.rufio/commands.rb` も可）に独自コマンドを定義し、`:名前` で実行します。

```ruby
command "hello" do
  ruby { "Hello from rufio!" }
  description "挨拶コマンド"
end

command "status" do
  shell "git status"
  description "Gitステータス"
end

command "build" do
  script "~/.config/rufio/scripts/build.rb"
  description "ビルド実行"
end
```

## ジョブとログ

シェルコマンド・スクリプト・ZIP 処理はバックグラウンドで実行され、その間もファイル操作を続けられます。ジョブが終わると通知が出ます。

**Jobs モード（`J`）**

| キー | 操作 |
|------|------|
| `j` / `k` | ジョブを選択 |
| `g` / `G` | 先頭 / 末尾のジョブ |
| `Space` | ジョブのログを表示 |
| `x` | 選択したジョブをキャンセル |
| `ESC` | 戻る |

**Logs モード（`L`）** は `~/.config/rufio/logs/` の実行ログを一覧表示します。`P` でログをプレビューし、`ESC` でプレビューを閉じ、もう一度 `ESC` で Files に戻ります。

## Config モード

`C` で `~/.config/rufio/` を開きます（なければ作成します）。移動・プレビュー・ファイル操作は Files モードと同じなので、設定やスクリプトを直接編集できます。設定ディレクトリの外へ移動すると Files モードに戻ります。

## シェル連携

`rufio --shell-init` は `rf` というシェル関数を出力します。`rf` で rufio を起動して `T` を押すと、終了してシェルが表示中のディレクトリへ移動します。`q` で終了した場合は移動しません。

```bash
# bash / zsh（~/.bashrc または ~/.zshrc）
eval "$(rufio --shell-init)"

# fish（~/.config/fish/config.fish）
rufio --shell-init fish | source
```

```powershell
# PowerShell（$PROFILE）
Invoke-Expression (& rufio --shell-init powershell | Out-String)
```

引数を省略すると、Windows では PowerShell 用、それ以外ではログインシェル（`bash`・`zsh`・`fish`）用を出力します。シェル起動のたびに Ruby を起動したくない場合は、`rufio --shell-init >> ~/.bashrc` のように一度だけ出力を追記してください。

## 設定

```
~/.config/rufio/
├── config.rb          # メイン設定（Ruby の定数）
├── script_paths.yml   # スクリプトパス
├── bookmarks.yml      # ブックマーク
├── commands.rb        # DSL コマンド
├── scripts/           # 個人スクリプト
└── logs/              # 実行ログ
```

### config.rb

```ruby
# ~/.config/rufio/config.rb

# 'en' または 'ja'（環境変数 RUFIO_LANG でも指定可）
LANGUAGE = 'ja'

# 色（HSL）
COLORS = {
  directory: { hsl: [220, 80, 60] },
  file: { hsl: [0, 0, 90] },
  executable: { hsl: [120, 70, 50] },
  selected: { hsl: [50, 90, 70] },
  preview: { hsl: [180, 60, 65] }
}.freeze

# キーの変更はアクション名で指定する。値は 1 キーの文字列
KEYBINDS = {
  bottom: 'G',
  search: 'S'
}.freeze

# `o` で使うアプリ（拡張子ごと）
APPLICATIONS = {
  %w[txt md rb py js json yml] => 'code',
  :default => 'open'
}.freeze

# `/` の検索から除外する拡張子（/ 始まりはディレクトリ・ファイル名）
SEARCH_EXCLUDED_EXTENSIONS = %w[.log /node_modules].freeze
```

`SEARCH_EXCLUDED_EXTENSIONS` を設定していない場合は、旧名の `GLOBAL_SEARCH_EXCLUDED_EXTENSIONS` も読み込みます。

`KEYBINDS` で使えるアクション名:

| 分類 | アクション（デフォルトキー） |
|------|------------------------------|
| 移動 | `move_up` (k), `move_down` (j), `navigate_parent` (h), `navigate_enter` (l), `top` (g), `bottom` (}), `refresh` (R) |
| ファイル | `open_file` (o), `preview` (P), `rename` (r), `delete` (d), `create_file` (a), `create_dir` (A), `move_selected` (m), `copy_selected` (c), `delete_selected` (x), `open_explorer` (e) |
| 選択・検索 | `select` (Space), `filter` (f), `search` (/) |
| ブックマーク | `add_bookmark` (b), `bookmark_menu` (B), `zoxide` (z), `start_dir` (0) |
| モード | `job_mode` (J), `config_mode` (C), `help` (?), `log_viewer` (L), `command_mode` (:), `quit` (q), `quit_cd` (T) |

以前のアクション名 `fzf_search`・`fzf_search_alt`・`file_search`・`file_search_alt`・`rga_search`・`global_search` は、いずれも `search` の別名として引き続き使えます。

### script_paths.yml と bookmarks.yml

```yaml
# ~/.config/rufio/script_paths.yml
- ~/.config/rufio/scripts
- ~/bin
```

```yaml
# ~/.config/rufio/bookmarks.yml
- path: ~/Documents
  name: Documents
- path: ~/projects
  name: Projects
```

### プロジェクト設定

プロジェクトのルートに `rufio.yml` を置くと、そのプロジェクト用のスクリプトパスを追加できます。

```yaml
# ./rufio.yml
script_paths:
  - ./scripts
  - ./bin
```

## 外部ツール

すべて任意です。インストールしていなければ、その機能を無効にするか組み込みの動作に切り替えます。`rufio -c` で検出状況を確認できます。

| ツール | 用途 | キー |
|--------|------|------|
| zoxide | ディレクトリ履歴 | `z` |
| bat | プレビューのシンタックスハイライト | — |

```bash
# macOS
brew install bat zoxide

# Ubuntu/Debian
apt install bat zoxide
```

## コマンドラインオプション

```bash
rufio [DIRECTORY]          # DIRECTORY で起動（省略時はカレントディレクトリ）
rufio -c                   # 依存関係をチェック（--check-health）
rufio --shell-init [SHELL] # rf シェル関数を出力
rufio --yjit               # YJIT を有効化（Ruby 3.1+）
rufio --zjit               # ZJIT を有効化（Ruby 3.4+）
rufio --native             # 実験的なネイティブディレクトリスキャナー
rufio --test               # FPS カウンターを表示
rufio -h                   # ヘルプ
```

## ネイティブエンジン

gem には macOS（arm64/x86_64）、Linux（x86_64/aarch64、glibc 2.17 以降または musl）、Windows（x64/arm64）向けの Zig ライブラリが同梱されています。その他のプラットフォームでは自動的に Ruby 実装を使います。

- **内容検索**: 並列スキャンとメモリ上のファイルキャッシュで、再検索は `rg` の約 10 倍速くなります。大文字・小文字のある非 ASCII 文字を含む検索語は Ruby で検索します。`RUFIO_NATIVE_SEARCH=0` で無効化できます。
- **ZIP**: エントリの伸長と 1 MiB 以上のファイルの圧縮を並列に行います（4 CPU・64 MB × 8 ファイルの計測で、Ruby より圧縮が約 4.6 倍、展開が約 3.2 倍高速）。アーカイブの検証は常に Ruby 側で行います。`RUFIO_NATIVE_ZIP=0` で無効化できます。

同梱バイナリの再ビルド（Zig 0.17 が必要）:

```bash
bundle exec rake native:build   # 全プラットフォーム
bundle exec rake native:check   # 同梱バイナリの検証
```
