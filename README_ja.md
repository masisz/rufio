# rufio

**Runtime Unified Flow I/O Operator**

日々のスクリプト作業を手元にまとめるターミナルファイラ。
ファイルを探し、その場所で Ruby・Python・PowerShell を実行し、ジョブとログを確認できます。
自分用の操作は Ruby で追加できます。

**日本語** | [English](./README.md)

1.6.0 の開発では、`s` / `/` と `F` を fzf から内蔵のあいまい検索画面に置き換えました（ファイルのプレビューと、開き直しを速くする一覧キャッシュつき）。
Zig の曖昧検索コア・Ruby フォールバック・非同期検索セッションで動作します。
詳細は[実装計画と計測結果](./docs/native_fuzzy_search_design_ja.md)を参照してください。

## rufioならではの点

rufio は、ファイルを探すところからスクリプトの実行、結果の確認までを一つの画面にまとめます。

- **ファイルのある場所からスクリプトを実行**: スクリプトのディレクトリを登録し、`:` → `@` + スクリプト名の一部 → `Tab` → `Enter` で呼び出せます。Ruby・Python・PowerShell を、いま開いているディレクトリで実行できます
- **ジョブとログで実行結果を追える**: バックグラウンドで実行しながらファイル操作を続け、`J` でジョブ、`L` で実行ログを確認できます
- **自分用の操作を Ruby で追加**: `~/.config/rufio/commands.rb` に小さな Ruby DSL で独自コマンドを定義できます。`~/.rufio/commands.rb` にも対応しています
- **インストール済みのツールと追加設定なしで連携**: rga で内容検索、bat でプレビューのシンタックスハイライト、zoxide でディレクトリ履歴から移動できます
- **Windows にも対応**: PowerShell スクリプトの実行に対応し、Windows のターミナルに合わせたキー入力処理を備えています
- **挙動をソースで追いやすい**: Ruby を中心とした実装で、必要な処理を自分で確認・修正できます。セキュリティに関する設計は [SECURITY.md](./SECURITY.md) にまとめています

## 特徴

### スクリプト作業のために

- **マルチ言語スクリプト対応**: Ruby, Python, PowerShell
- **スクリプトパス管理**: 複数のスクリプトディレクトリを登録・管理
- **コマンド補完**: `@`プレフィックスでスクリプトをTab補完
- **ジョブ管理**: バックグラウンドでスクリプト/コマンドを実行
- **実行ログ**: すべての実行結果を自動記録

### ファイルマネージャーとして

- **Vimライクなキーバインド**: 直感的なナビゲーション
- **リアルタイムプレビュー**: ファイル内容を即座に表示（`bat` によるシンタックスハイライト対応、`.zip` はエントリ一覧）
- **表を行列で表示**: `.csv` / `.tsv` / `.tab` / `.xlsx` / `.xlsm` / `.ods`、および `sqlite3` コマンドがあれば SQLite のデータベースを、列見出し付きのグリッドで表示します。スクロール中もヘッダ行は固定され、UTF-8・UTF-16・CP932・EUC-JP を自動判定して読み込みます
- **シート・テーブルの切替**: `[` / `]` で Excel のシートや SQLite のテーブルを切り替えます。表示しているものだけを読み込みます
- **セル間を移動**: プレビューモード（`P`）で `hjkl` によりセルカーソルを動かせます。カーソルに合わせて縦横にスクロールします
- **`y` でコピー**: カーソル位置のセルを（`Y` で行全体を）クリップボードへコピーします。ファイル一覧では選択中（またはカーソル位置）のパスをコピーします。コマンドがない環境では OSC 52 を使うので SSH 越しでも動きます
- **高速検索**: 内蔵のあいまいファイル名検索とrgaによる内容検索に加え、PDF・Excel・PowerPointも読める全ブックマーク横断検索を内蔵
- **ZIPの展開・圧縮**: 選択したアイテムをバックグラウンドで展開・圧縮
- **パスへ移動**: コピーしたパスを `:cd` に貼り付けて移動
- **ブックマーク**: よく使うディレクトリに素早くアクセス
- **zoxide連携**: スマートなディレクトリ履歴

テキストのプレビューは先頭64 KiBまで読み込みます。PDFの本文はプレビューせず、ファイル移動時の読み込みを省きます。

`.csv` / `.tsv` / `.tab` / `.xlsx` / `.xlsm` / `.ods` と SQLite（`sqlite3` コマンドがある場合。拡張子ではなくファイル先頭のシグネチャで判定します）は行列（グリッド）で表示します。テキスト形式は先頭 512 KiB まで読み込みます。プレビューモード（`P`）では `hjkl` でセルを移動し、`g`/`}` で先頭行・最終行、`0`/`$` で先頭列・最終列へ移動できます。`y` でカーソル位置のセル、`Y` で行全体をクリップボードへコピーでき、`[` / `]` でシートやテーブルを切り替えられます。ファイル名の下の行にセル番地と列名（`R3C2 price`）とコピー結果が出ます。読み込み上限や区切り文字、ヘッダ行の扱い、文字コードは `config.rb` の `TABLE_PREVIEW` で変更できます。

### クロスプラットフォーム

- **macOS**: ネイティブサポート
- **Linux**: ネイティブサポート
- **Windows**: PowerShellスクリプト対応

## インストール

```bash
gem install rufio
```

または、Gemfileに追加:

```ruby
gem 'rufio'
```

## クイックスタート

### 1. 起動

```bash
rufio           # カレントディレクトリで起動
rufio /path/to  # 指定したディレクトリで起動
```

### 2. スクリプトパスを登録

1. スクリプトを配置したいディレクトリに移動
2. `B` → `2` でスクリプトパスに追加

### 3. スクリプトを実行

1. `:` でコマンドモードを起動
2. `@` + スクリプト名の一部を入力
3. `Tab` で補完
4. `Enter` で実行

## キーバインド

よく使うキーです。すべてのキーとモードは **[操作ガイド](./docs/guide_ja.md)** を参照するか、rufio の中で `?` を押してください。

| キー | 操作 |
|------|------|
| `j/k`、`h/l` | 上下移動 / 親ディレクトリ / ディレクトリに入る |
| `g/}` | 先頭 / 末尾 |
| `P` | 全画面プレビュー |
| `Space` | 選択 |
| `m/c/x` | 選択したアイテムの移動 / コピー / 削除 |
| `z` | 選択したアイテムの展開・圧縮（`.zip`）。未選択時は zoxide 履歴 |
| `a/A`、`r`、`d` | ファイル / ディレクトリ作成、リネーム、削除 |
| `f`、`s`、`F` | フィルター、あいまいファイル名検索、rga で内容検索 |
| `G` | 全ブックマーク配下のファイル名・内容（PDF・Excel・PowerPoint も）を横断検索 |
| `b`、`B`、`1-9`、`Tab` | ブックマーク追加、メニュー、ジャンプ、次のブックマーク |
| `:` | コマンドモード（`@スクリプト`、`rake:タスク`、`!シェル`、`cd <パス>`） |
| `J`、`L`、`C` | ジョブ、ログ、設定ディレクトリ |
| `?` | ヘルプ |
| `q`、`T` | 終了、終了してシェルを現在のディレクトリへ移動 |

Gモードでは `↓` / `↑` または `Ctrl+J` / `Ctrl+K` で次／前の検索結果を選択し、`Enter` で開きます。Ghosttyなどのアプリケーションカーソル形式の矢印キーと拡張Ctrlキー入力にも対応しています。

## 開発

### 必要な環境

- Ruby 2.7.0以上

### 開発版の実行

```bash
git clone https://github.com/masisz/rufio
cd rufio
bundle install
./bin/rufio
```

### テスト

```bash
bundle exec rake test
```
